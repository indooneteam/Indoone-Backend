# Indoone Backend

Backend foundation for the Indoone AI + automation platform.

## Initial direction

- API-first backend
- Firebase Authentication token verification
- Company-scoped data and integrations
- AI chat and automation pipeline
- Runtime company data fetching through authorized APIs
- Usage and balance tracking

## Development

The first milestone is a minimal API that accepts a user message and returns an AI response. Company integrations and runtime data fetching will be added after the base service is working.
